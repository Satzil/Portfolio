2. TECH STACK FOR THE SITE
==============================================================================
Stack: plain HTML + CSS + a small amount of vanilla JS. No framework,
no build step, no node_modules. Why this is the right choice here:
  - Zero build means the site is just files; opens in any browser instantly.
  - No dependency-rot. The site you ship today still works in 5 years.
  - Hosting is trivial — GitHub Pages, Netlify drop, or even a static S3
    bucket all work in minutes.
  - Faster cold-load than any React bundle, which is the actual point of
    a recruiter-facing site.
  - Lets Satya edit content directly in HTML later without remembering JSX.

What we'll use:
  - HTML5         : semantic tags (<header> <section> <article> <footer>).
  - CSS3          : custom properties (CSS variables) for the palette,
                    Flexbox + CSS Grid for layout, @media for responsive.
                    No CSS framework — Tailwind isn't needed at this size.
  - Vanilla JS    : ~80 lines total, no libraries:
                      * IntersectionObserver -> reveal-on-scroll fade-up
                      * IntersectionObserver -> count-up animation for stats
                      * mobile nav toggle
                      * smooth-scroll polyfill (optional; modern browsers
                        already support scroll-behavior: smooth in CSS)
  - Google Fonts  : <link> tag for Inter + JetBrains Mono. No npm.
  - SVG icons     : inlined directly in HTML (email, LinkedIn, GitHub,
                    download, arrow). Copy from lucide.dev or heroicons.com
                    as needed. No icon library required.

Project structure:
  /portfolio
    index.html              (the whole page, all sections)
    style.css               (single stylesheet)
    script.js               (~80 lines of vanilla JS)
    resume.pdf              (copied from Deep_Learning_Resume.pdf)

      /projects              (renamed, optimized project images)

That's it — 3 files at the root, an /assets folder, and the resume.

3. DESIGN LANGUAGE (LIGHT MODE)
==============================================================================
Palette (Tailwind values):
  Background base   : #FAFAF7 (warm off-white)  -> bg-stone-50
  Surface / cards   : #FFFFFF                   -> bg-white
  Border / dividers : #E7E5E4                   -> border-stone-200
  Primary text      : #0C0A09 (near-black)      -> text-stone-950
  Muted text        : #57534E                   -> text-stone-600
  Accent (primary)  : #1E40AF (deep indigo-blue) — trust, technical
  Accent (success)  : #047857 (emerald-700)     — for metrics / wins
  Highlight tint    : #EFF6FF (indigo-50)       — soft chip backgrounds

Why this palette: the warm off-white feels premium (not the harsh #FFFFFF
that screams "default template"). Deep indigo + emerald reads as serious /
engineering, not flashy. Two accents max — anything more looks unfocused.

Typography:
  Headings  : Inter (700/800), tight tracking, large display sizes.
  Body      : Inter (400/500), 16-17px base, line-height 1.6.
  Numbers   : "JetBrains Mono" or "Space Grotesk" for the stats strip
              and project metrics — gives technical character.

Spacing rhythm:
  - 8px base unit.
  - Section vertical padding: py-24 desktop / py-16 mobile.
  - Max content width: 1200px (max-w-6xl), centered.

Visual motifs:
  - Generous whitespace; never crowd the cards.
  - Subtle shadow-sm on cards, lift to shadow-lg on hover.
  - 1px stone-200 borders rather than heavy shadows.
  - Soft gradient washes only on the hero (top-right indigo blob, low opacity).
  - Rounded-xl (12px) everywhere; rounded-2xl on hero/stat tiles.
  - No skeuomorphism, no glassmorphism — flat, modern, confident.

Motion:
  - Fade-up + 8px translate on scroll (0.4s ease-out, once only).
  - Number count-up on stats strip when scrolled into view.
  - Card hover: 2px lift + image zoom 1.03x. That's it.
  - NO autoplay carousels, NO parallax. Recruiters skim, motion gets in the way.

9. DEPLOYMENT
==============================================================================
Static site, so any of these work in minutes — pick the most familiar:

  Option A — GitHub Pages (recommended, free, simplest):
    1. git init && git add . && git commit -m "portfolio v1"
    2. Create a public repo, e.g. github.com/<you>/portfolio
    3. git push -u origin main
    4. Repo Settings -> Pages -> Source: main branch / root
    5. Live at https://<you>.github.io/portfolio in ~30 seconds.

  Option B — Netlify drop (no git required):
    1. Drag the /portfolio folder onto app.netlify.com/drop
    2. Get a *.netlify.app URL instantly. Connect a custom domain later.

  Option C — Vercel:
    1. Connect GitHub repo at vercel.com.
    2. Framework preset: "Other" (no build command, output directory ".").

Local preview while building (no node needed):
    python3 -m http.server 8000      # then open http://localhost:8000
  Or just double-click index.html — it opens in the browser as a file://
  URL and works fine for development.

Domain idea (optional, ~$10/year):
